# Our Little Archive — Front-end starter

This starter follows the supplied 9-page design reference:
- Home
- Login
- Dashboard
- Photos
- Videos
- Journal
- Documents
- Add a Memory
- Font / color system

## Backgrounds
The CSS expects these files:
assets/backgrounds/home-bg.jpg
assets/backgrounds/login-bg.jpg
assets/backgrounds/dashboard-bg.jpg
assets/backgrounds/photos-bg.jpg
assets/backgrounds/videos-bg.jpg
assets/backgrounds/journal-bg.jpg
assets/backgrounds/documents-bg.jpg
assets/backgrounds/add-memory-bg.jpg

Replace each with your own designed background image. No separate background CSS is needed per HTML page.

## Logo
Replace the LOGO placeholder in each page with your finished logo image.

## Fonts
Put your actual font files in assets/fonts/ using the names referenced in css/style.css.
If a font file is missing, the browser will use the fallback font.

## Current functionality
This version is intentionally front-end only:
- navigation works
- responsive layouts work
- login is a visual demo only
- upload form is a visual demo only
- no files are actually uploaded yet
- no real accounts/database exist yet
